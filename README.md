# Customer Support & Ticket Analytics Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze customer support operations and monitor key performance metrics.

## Key Metrics
- Total Tickets: 100
- Closed Tickets
- Open Tickets
- Average Resolution Time
- Department-wise Ticket Distribution
- Ticket Priority Analysis

## Tools Used
- Power BI
- Excel
- DAX
- Data Visualization

## Dashboard Features
- Ticket Status Tracking
- Resolution Time Analysis
- Department Performance Monitoring
- Priority-wise Ticket Breakdown
- Interactive Filters and Slicers

## Business Insights
- Identified departments with the highest ticket volume.
- Monitored ticket closure efficiency.
- Tracked workload distribution across teams.
- Highlighted support performance trends.
